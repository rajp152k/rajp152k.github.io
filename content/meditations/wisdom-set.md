most the techniques and tooling (second brains, retention strategies, etc) seem to be irrelevant lately

then i analyse higher order patterns and try to a build something of a wisdom set - something that helps me better parse the epistemological world around.  

this initiative sprouts from the problem of not knowing what's worth knowing.
