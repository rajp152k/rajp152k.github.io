# Writing

One meditation is one Markdown file in `meditations/`.

```md
---
title: Short descriptive title
date: YYYY-MM-DD
---
```

- State the claim or observation directly.
- Define terms when ambiguity changes the claim.
- Separate observation, inference, and speculation.
- Use headings, links, examples, and equations only when they clarify.
- Use `$$` on separate lines for display mathematics.
- Name files with lowercase hyphenated slugs.
