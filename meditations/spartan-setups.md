---
title: spartan setups
date: 2026-08-21
---

i've given up on monitors again and choosing to work with a single laptop screen - multiplexing, with tmux, with intent, analysing your old patterns and building tooling on minimal tech helps clear out bandwidth to get things done instead of swivelling my head around from screen to screen.  

i was using notebooks for a while to think but have started to experience an increased cognitive working memory capacity lately - don't need to write down things and can handle multiple threads better than before.  

this was an uphill battle - transferring quality complexity to my brain and delegating the boring stuff to the computer.
