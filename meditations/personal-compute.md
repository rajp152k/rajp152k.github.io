---
title: personal compute is simpler
date: 2026-08-24
---

i had been thinking about how to better use all the compute that i have for a while - a collection of workstations, phones and a vps..   

there's an explicit focus on minimalism tho (i'm blogging through one of my workstations right now, which i've sshed into from my phone, where i use vi in tmux)..  

the nature of things that we use is actually fairly simple. over engineering abstractions is a habit i'm slowly shedding off. 

for instance, i paused writing for a while and continued from this sentence onwards from a tmux client on the workstation.   

a lot of the most basic applications that we use, tend to the masses - when i started building personal first software - a lot of constraints around enabling non-functional requirements of the whole ecosystem limit how creative you could be in your ideas.  

also, you don't need fancy ui - a simple text file that is picked up by a program and processed is extremely simple and convenient - it's all just text and processes that process that text in any which way you want.  

i was thinking of building an over engineered complex ecosystem of composible set of tooling that i could deploy over my personal compute network - but i could very well build with just scripts and config files and local sqlite that just syncs over my drive.  

building for superusers is fun - for you can assume competence and jump through a whole bunch of conceptual hoops without having to build a bunch of safety constructs.  
i also used to just complicate blogging a whole bunch before this iteration() - trying to sound like someone worth reading - not caring about that stuff anymore has been liberating - you don't need to have uniformity - a basic logging practice is all that you need - analysing the blog is something that can be done later on with the raw writes that you have..  

this is also mindset i have with my work journals know - have a raw day based write log and analyse later on whenever you need to - llms have taken away the need to pre-think how i store information - plain text is just all that i need..  

i was sad for a while when i left emacs around a couple of months ago but am slowly starting to enjoy using computers again - it's much more raw and simple - feels like moving on to using a motorcycle instead of a modded out pickup truck .. the llms just handle the truck stuff for you now, pretty ephemerally.
